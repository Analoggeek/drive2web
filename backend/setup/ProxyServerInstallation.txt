== New Proxy Setup ==

1. Upgrade to latest Ubuntu LTS
2. Create swap
3. Install nginx
4. Install certs
5. Install nginx_proxy
6. Add server IP to DrvTW IP trust list
7. Enable access from server IP
8. Update DNS to point drv.tw to new server
9. Edit sysctl.conf
#jcw
net.ipv4.tcp_fin_timeout=30
net.ipv6.conf.all.disable_ipv6=1
net.ipv6.conf.default.disable_ipv6=1
vm.swappiness=10
